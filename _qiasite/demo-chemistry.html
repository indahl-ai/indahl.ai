Who it’s for
A pharma or materials R&D team that computes molecular ground-state energies on IBM hardware with dynamic circuits, and needs a number it can trust before moving to bigger molecules.
Their run
The hydrogen molecule’s energy by phase estimation: five phase bits read mid-circuit with feedforward, IBM’s default layout, bits taken as read.
What changed
The circuit is almost all two-qubit gates, so how often each phase bit comes out right is set by gate error. Before the run, the error of the two gates it uses was measured and each of its three qubits’ readout was read that day. The correction uses those measured values. The calibrated correction and the stated one use the same readout table, so the gap between them is the gate error alone. Nothing is added to the client’s circuit.
Outcome
Calibrated against the client: BELOW (lower energy error, and fewer shots with a wrong bit) on all three chips, in both runs. Calibrated against a correction from IBM’s stated figure: lower every time, CONSISTENT on energy. On shots with a wrong bit, BELOW or CONSISTENT.
