Who it’s for
Error-correction teams running surface-code memory experiments on IBM cloud hardware: university and national-lab groups, and companies building decoders or control stacks.
Their run
A distance-3 surface-code patch held for 1 to 4 rounds. Each round count is compiled by the client’s own default compile, and one standard decoder turns the check record into a logical answer.
What changed
Every mid-circuit readout turns the phase of the data qubits waiting beside it. In a surface code that turn is an error in every round, and IBM’s calibration record has no field for it. An earlier job measured the turn on the exact qubits that hold each data qubit after each readout. The main job undoes it with a rotation that is applied in software: no pulse, no time, no gate added to the client’s circuit.
Outcome
Calibrated against the client: in run 1, BELOW (fewer failures) per round and at every round count on all three chips. In run 2, BELOW on ibm_kingston and ibm_fez. A control the correction should not move, the Z checks, moved by at most 0.003. Its interval was wider than the margin set before the run, so its word is CANNOT TELL.
