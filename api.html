Measurements as tools

The developer guide, with quickstart, the answer format, receipts and the OpenAPI document: Developers.

The QIA calibration tools and checks on material a person brings can be run by an agent or a script, with no key and nothing to install. Each answer carries its source page, the time it was read and the terms. Outcomes are above, below, consistent or cannot tell, relative to what was stated. Nothing here writes anything.

Add it to an agent

The MCP server is at https://indahl.ai/mcp and speaks the Model Context Protocol over HTTP. In Claude Code:

claude mcp add --transport http indahl https://indahl.ai/mcp

Any client that takes a remote MCP server can use the same address. Start with list_divisions.

Tools

ToolReturns
qia_calibration_checkCheck the calibration record IBM publishes for an IBM Quantum processor, for the qubits a circuit will use.
qia_run_checkFor a run already done on an IBM Quantum processor: which published calibration record was in force at the start, every record IBM stamped during the run window that the indahl.ai index saw, each change in T1, T2 and the readout error figures on the run’s qubits, records with the same stamp but different figures (CONFLICT), and the package flags on the record in force.
qia_qubit_historyEvery distinct T1, T2 and readout-error measurement IBM published for one qubit of an IBM Quantum processor in the indahl.ai saved index (up to 30 days), deduplicated by IBM’s measurement date.
qia_measuredFor an IBM Quantum processor and the qubits a circuit will use: IBM’s stated readout error and T1 with the entry date and age, beside our latest hourly measurement of the same qubit (value, 99.9 % / 99.99 % interval, job id, window in UTC, job file URL), the outcome word of the published calibration rule with a plain sentence of which way it points, and the qubit’s last hourly runs (median, range, outcome counts, only runs that passed known-good).
paper_checkCheck one paper by DOI or arXiv id: retraction, correction and expression-of-concern notices registered in Crossref (from publishers, and entries Crossref attributes to Retraction Watch), the current arXiv version, whether the arXiv comment says the paper was withdrawn, and whether a page answers at each code and data link stated in the abstract (the contents are not read).
paper_statisticsRead the full text of one arXiv paper from arXiv’s HTML version and recompute every reported t, F, chi-square, r and z statistic and every count-and-percentage pair from the paper’s own numbers, references cut.
check_reported_statisticsRecompute the statistics in text pasted from a paper: every reported t, F, chi-square, r and z statistic with its p value, from the statistic and its degrees of freedom (the method of statcheck), and every count-and-percentage pair such as “45 of 120 (37.5%)” from its counts, allowing for rounding.
number_checkExtracts each number in a report (with %, currency, separators, decimals, k/M/B suffixes) and its context words, and looks for it in a source given as a DOI, arXiv id, URL or pasted text.
interval_verdictCompares an estimate and its interval (low and high, or se with a level) with a stated value, and with the stated value plus or minus a size that would matter.
triangulate_readingsTakes two or more readings (value with se or low/high).
claim_wording_checkRule-based scan of result sentences for wording patterns such as proof language, causal verbs, "no effect" from non-significance, "significant" without a test, first/novel, always/never/all, "the same" for a non-difference, robust and clearly.
package_checkCheck one PyPI project by name, live, with the rules of the PKGLICENSE and PKGINSTALL desks: whether the newest release carries files pip can install on any platform (an sdist or a universal wheel), is limited to certain platforms, is yanked or has no files, and whether the license the package states agrees with the license of its linked GitHub repository, compared by family.
model_checkCheck one Hugging Face model by id, live, with the rules of the HFSIZE and HFLICENSE desks: whether the size in its name agrees with the parameter count of its safetensors weights (0.70 to 1.35 times), and whether the license on its card agrees with the license file in the repository, compared by family.
link_rotCheck whether the code and data links stated in one arXiv paper’s abstract and comments still answer, or check up to 10 links given directly, live.
arxiv_version_driftCheck one arXiv paper live: its current version, when it was first posted and last updated, whether its comment says it was withdrawn, and, given the version read, whether the title or the numbers stated in the abstract changed since.
source_checkExtracts DOIs, arXiv ids and URLs from text or a refs list and reads each: RESOLVES, BROKEN, RETRACTED, CORRECTED or CANNOT TELL, with Crossref title and registered notices, the arXiv current version, or the HTTP status.
quote_checkFinds quoted spans in a draft (straight and curly double quotes, lines marked with ">") and searches each in a source given as a DOI, arXiv id, URL or pasted text.
list_divisionsList QIA and every live desk of indahl.ai with a one-line description and its page.

The same tools as plain JSON

curl 'https://indahl.ai/api/v1/qia_calibration_check?processor=ibm_kingston&qubits=0,1'
curl 'https://indahl.ai/api/v1/list_divisions'
curl https://indahl.ai/api/v1

The OpenAPI description is at /api/openapi.json. Tool responses are cached for a minute and the tool list and the OpenAPI file for ten minutes.
