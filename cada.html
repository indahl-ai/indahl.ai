Division: ATLAS

Public DNS filters, checked against domain alerts

Free public resolvers advertise blocking of malware and phishing domains. Two public lists of bad domains, the Phishing.Database active domain list and the CERT Polska domain list for blocking, are read. Each domain that is new since the last read is asked about at first sight, then after 1 hour, 6 hours and 24 hours, through three resolvers that state no filtering (Cloudflare 1.1.1.1, Quad9 9.9.9.10 and Google 8.8.8.8) and through each filter. A filter blocks a domain when it refuses while the unfiltered resolvers answer. Only DNS questions are asked. No listed host is contacted and nothing is downloaded. The rules were committed before the first question.

Loading.

Each cell is the share of live listed domains the resolver refused, with the 95% interval, and the count behind it. It is a measured share and is not compared with any provider claim, so no cell carries an outcome word and none is cannot tell. A query that returns no answer is a failed read, counted apart and outside every share. No ranking.

Plan, code and trend history for this page are public: cada. Every plan was committed before the data it describes.
