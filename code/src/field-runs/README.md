# Field Runs

Our own connectors, plugins and MCP servers, run for real on our own work. Each run keeps what went in, what came out and the receipt, including the parts that failed.

- `worker-clean/`: the indahl.ai worker cleaned for public release with indahl-relay (the chain), indahl-rubicon (criteria frozen first) and indahl-ccr (approval bound to the shipped bytes).
- `fsck-own-config/`: indahl-fsck run on our own MCP setup.
