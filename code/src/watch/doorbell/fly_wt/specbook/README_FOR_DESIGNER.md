# The Heurémen specbook, passed to the designer (the owner, 20 Nov 2026: "drop the Heuremen specbook in the designer's lane")

The book is the house's written standard for anything a stranger sees: pages, footers, mail, letters, bills, invoices, the mark and its colors.
Read it before you build or change any page, notice, deck or document.

## What is here
| File | What it is |
|---|---|
| `SPECBOOK_v1.2_OUTWARD_KIT.md` | **The current book.** Start at §0 ("The book wins"), then §0a, §0b, §0c (the owner's dated amendments), then §1 (names) and the section for the thing you are making. |

| `assets/` | The mark and lockups (svg, png, ico, social sizes). Use these files; never redraw the mark. |

## How to use it
1. **The book wins.** If a page and the book disagree, the page is wrong.
2. **Only the owner amends the book**, in writing, with a date. Do not edit these files. If you think a rule is missing or wrong, ring with the section and the sentence.
3. **The master is on the house Mac.** the operator pushes a fresh copy here when the book changes.

## Standing orders given since the book's last amendment (25 Oct 2026)
These are the owner's, as the operator holds them. They are not written into the book yet. Where one of them and the book disagree, the later order holds.
- **Public pages are technical only.** Nothing about the owner: no career, bio, quotes or anecdotes (14 Nov).
- **No About page, no byline, no named operator on indahl.ai.** The work and the data speak (16 Nov).
- **"House", never "flock", on any public surface.** Internal files keep "flock" (the gate refuses it on served pages).
- **American spelling** in every public text (18 Nov).
- **Corrections are kept and dated, never the lead** of a page, release or example (18 Nov).
- **Release copy is short and direct.** Action sentences; proof lives on the site, not in the text (18 Nov).
- **One contact path.** The engagement form only; never an email address on a site (19 Nov, and §0b.7).
- **Two sites, two offers.** indahl.ai is research; the QIA site is business. Read the live page before relaying an offer (20 Nov).
- **AI/ML leads** wherever lines of work are listed (20 Nov).
- **No per-organization pages** (20 Nov).
- **Receipts are internal.** No public receipt pages or links (15 Nov).
- **The public clock is HST** (Heuremen Standard Time), never whose clock it is (31 Oct).
- **Neutral public surfaces.** No religion, no nationalism; straight science (24 Oct).
- **No wasted space.** No minimum height on loaded boxes, tight first columns, no duplicate columns (16 Nov).
- **No counts of our own things in a title, heading or lead** (§0b.5; repeated since).
