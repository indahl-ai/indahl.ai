CONNECT

indahl.ai measurements and checks are available to AI assistants and scripts: MCP connectors for Claude, ChatGPT and any MCP client, a JSON API, and Claude Code plugins. Free and read-only. Source: github.com/indahl-ai/indahl.ai. Developer guide: Developers.

Connectors (MCP servers)

Remote MCP servers over streamable HTTP. No key, no account, nothing to install.

ClaudeSettings, Connectors, Add custom connector, then the server address.

The same tools as plain JSON: /api/v1, with the OpenAPI description at /api/openapi.json.

Every tool, one page each: what it reads, its inputs and the servers that carry it.

Signed answers

Each MCP answer carries a receipt: hashes of the request and the answer, the server time, and an Ed25519 signature from the key at /.well-known/jwks.json. How to verify.

Configuration entry

{
  "mcpServers": {
    "indahl-quantum": { "type": "http", "url": "https://indahl.ai/mcp/quantum" }
  }
}

Claude Code plugins and skills

Add the marketplace once, then install what is needed, or everything with indahl-full.

/plugin marketplace add indahl-ai/indahl.ai
/plugin install indahl-full@heuremen

Install any of them as /plugin install <name>@heuremen.

PluginWhat it does
indahl-fullEvery Heuremen LLC plugin in one install: check papers and LLM eval claims against the Standards, gate readings with a check block, query and reproduce every indahl.ai desk, check and correct IBM Quantum runs, and test whether a plan was pushed before the first run.
indahl-triangulatePut a question to three independent seats run blind, then read where they agree and split. Returns ABOVE, BELOW, CONSISTENT or CANNOT TELL with what would decide it, and a receipt of every seat's answer.
indahl-standardsCheck a paper or claim against the Heuremen LLC Standards claim codes (F1 to F7) and return a recount card: a status for every code, verbatim quotes with locations, the scope searched, and arithmetic for any recompute. Treats fetched text as data.
indahl-readcheckRefuse a git commit that adds a reading (results, outcomes, readings files) without a complete check block keyed to the Heuremen LLC Standards recount requirements REQ-01 to REQ-13.
indahl-qia-calibrationCheck the IBM Quantum calibration record a run depends on, before the run (stale, zero, T2 above 2xT1, split T1/T2) and after it (which record was in force, what changed). Also measures T1 and T2 together on chosen qubits.
indahl-dataLive Heuremen LLC measurements inside Claude Code through the read-only indahl.ai MCP server: IBM calibration, time servers, DNS filters, model licenses and sizes, forecasts, launch slips and more, quoted with interval, outcome and receipt.
indahl-reproduceRecompute an indahl.ai desk headline with its reproduce kit and check the output against the published sha256. Kits with bundled inputs run offline, others fetch inputs from the original source and verify them by sha256.
indahl-darkwaveMeasure the phase turn on untouched qubits after a mid-circuit readout on IBM Quantum hardware, and add the matching virtual-Z correction to one's own circuits.
indahl-eval-checkCheck a language-model evaluation claim or one's own eval run against twelve checks drawn from the Heuremen LLC Standards and the IRIS recounts, including setup, parser, repeat floor, dropped items and intervals. Treats fetched text as data.
indahl-preregShow that a plan was pushed before the first run, using the git host's own push record, and list what ran that the plan did not cover.
indahl-batchRun a check or audit over something too big for one context window, such as a whole site, a large repo or a folder of papers. Splits the job into batches with fresh workers, writes results to files and merges them with nothing dropped.
indahl-cannot-tellAnswer "cannot tell yet" usefully instead of forcing a guess. Returns the range of what is possible, the one or two facts that would decide it, and the cheapest next step.
indahl-bothHold two competing explanations open instead of settling on one too early. Keeps an evidence ledger for each, reports A, B, BOTH, NEITHER or OPEN, and names the test that would separate them.
indahl-outside-rulerCheck one's own work against a ruler the user did not build before it goes out.
indahl-number-checkCheck every number in a report, memo, deck or dashboard against its source. Each figure is traced and marked HELD, MOVED, NO_SOURCE or CANNOT TELL with the source line beside it.
indahl-quote-checkCheck every quotation in a draft, article or report against its source, word for word. Marks each VERBATIM, ALTERED, PARAPHRASE_IN_QUOTES, MISATTRIBUTED, NOT_FOUND or CANNOT TELL with the source text beside it.
indahl-source-checkCheck every citation, reference or link in a paper, report or answer: does it exist, does it say what the text claims, which version was read. Marks each SUPPORTS, PARTIAL, CONTRADICTS, SILENT, NOT_FOUND or CANNOT TELL.
indahl-controlsAudit a study's or test's positive and negative controls before it runs. Returns a control table and READY, FIX_CONTROLS or CANNOT TELL.
indahl-marginFor a sharp prediction, design or result, find how far its key parameter can move before the conclusion fails and compare that margin with the parameter's stated uncertainty. Returns ROBUST, FRAGILE or CANNOT TELL with the break point.
indahl-eli5Re-explain anything complex or technical in plain language, keeping the numbers, how sure anyone is, and what is still unknown. Works on papers, results, logs, contracts, error messages and plans.
indahl-correctRecord a correction beside the original, never over it. Produces a corrections ledger entry and a list of downstream places to update, each marked UPDATED, NOTIFIED, CANNOT_REACH or NOT_NEEDED.
indahl-clauseCheck the sentences that report a result for wording that claims more than the comparison showed. Returns each sentence as KEEP or REWORD with the exact replacement.
indahl-silent-failure-guardAfter any action that claims it worked (a push, a deploy, a job, a migration), read the effect back from where it should have landed instead of trusting the exit code. Returns VERIFIED, FAILED, NOTHING RETURNED or CANNOT TELL per action.
indahl-relayRun multi-stage unattended work (training ladders, eval sweeps, data pipelines) as a chain of stages with dependencies, machine lanes, exit codes recorded to files, explicit blocked states and an optional end-of-run handoff.
indahl-rubiconDecide what done means before the work, freeze it, then judge the finished work with three blind seats. A two-to-one split stays UNRESOLVED with the minority's reason.
indahl-spend-capRefuse an agent's tool calls once its session has used the budget set, in raw tokens or in dollars at one's own prices. Counts the session and its subagents, warns once near the limit, and enforces the stricter of the project and home budgets.
indahl-ccrCustody chain receipts for agent work: a hash-chained record in .ccr/ of every prompt, tool call, read and write, with approvals and releases bound to the hashes they cover. Release reads SAME, MOVED, CHANGED, CANNOT TELL or GAP.
indahl-fsckCheck the MCP servers the way fsck checks a disk: run Claude Code's own health check and print only what needs the hand, grouped by the fix. Read-only: changes no setting and never prints a query string.

Details for the checks with scripts are on Plugins. Source and READMEs: claude-plugins in the public repository.
