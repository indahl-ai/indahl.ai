CHECK QUOTATIONS AGAINST A SOURCE

quote_check

Finds quoted spans in a draft (straight and curly double quotes, lines marked with ">") and searches each in a source given as a DOI, arXiv id, URL or pasted text. Labels each VERBATIM (verbatim up to case, whitespace, and quote and dash style), VERBATIM_WITH_GAPS (an ellipsis whose omitted source words are printed), ALTERED (with the source’s exact words and a word-level difference), PARAPHRASE_IN_QUOTES (by shared content words only), NOT_FOUND (full text read only) or CANNOT TELL (abstract-only, paywalled or very short source, scope named). String matching only: it does not judge meaning.

Inputs

InputRequiredWhat it takes
textyesDraft containing quotations, or one quote (up to 20000 characters).
sourcenoDOI, arXiv id or http(s) URL of the source.
source_textnoPasted source text (used instead of source).
attributed_tonoOptional name. The tool only reports whether this name appears near the matched text; it does not confirm who said or wrote the words.

Use it

Add any of these MCP servers to Claude, ChatGPT, HuggingChat or another MCP client. No key and no account.

ServerAddress
indahl.aihttps://indahl.ai/mcp

Then ask the assistant to use quote_check with text, and to give each outcome with the source it read.

Or call it directly: https://indahl.ai/api/v1/quote_check?text=… (OpenAPI).

What it does with a request

Read-only. It sends the one item named to the public source it checks, and nothing else. The server keeps nothing from the request. Each answer carries a signed receipt. How the server handles requests.
