COMBINE INDEPENDENT READINGS

triangulate_readings

Takes two or more readings (value with se or low/high). Returns pairwise gaps with z and ABOVE / BELOW / CONSISTENT per pair, an inverse-variance combined value with chi2 per dof (quoted only if the chi-square p is at least 0.05; se inflated by sqrt(chi2/dof) when above 1, factor printed), an outlier (three or more readings only) when one reading accounts for a disagreement, pairwise comparisons not corrected for multiplicity, and an overall outcome against an optional stated value. Assumes the readings are independent and normal; shared sources are not detected.

Inputs

InputRequiredWhat it takes
readingsyesObjects {label, value, se} or {label, value, low, high}.
statednoOptional claimed value to compare the combined reading with.
levelnoInterval level, default 0.95.

Use it

Add any of these MCP servers to Claude, ChatGPT, HuggingChat or another MCP client. No key and no account.

ServerAddress
indahl.aihttps://indahl.ai/mcp

Then ask the assistant to use triangulate_readings with readings, and to give each outcome with the source it read.

Or call it directly: https://indahl.ai/api/v1/triangulate_readings?readings=… (OpenAPI).

What it does with a request

Read-only. It reads data indahl.ai has already published and sends nothing onward. The server keeps nothing from the request. Each answer carries a signed receipt. How the server handles requests.
