When the USGS states the odds of aftershocks, what follows?

After a significant earthquake in the United States or its territories, and after some large earthquakes elsewhere, the USGS publishes an aftershock forecast and updates it on a schedule, daily at first and then weekly for a year. Each version states, for the next day, week, month and year, the chance of at least one earthquake at or above magnitude 3, 4, 5, 6 and 7, and a range for how many. The USGS scientific background calls that range “the 95% confidence range” and says its 2.5 and 97.5 percent points are approximate for a number that can only be a whole number.

The USGS event catalog keeps every version of every forecast. This page reads all of them, from 2019-07-06 to 2026-11-20, and uses a window only when the version was stamped in the catalog before the window opened. The count for each window comes from the same catalog, in the zone the forecast states for itself, for earthquakes at or above the forecast magnitude, leaving out the mainshock. A window is read once it has been closed for a week. All four known-good checks passed on this run.

Windows from one sequence overlap. Every version of one forecast counts the same aftershocks, and the day, week, month and year windows of one version are nested. So every interval here is given two ways. The Wilson interval treats rows as independent. The second resamples whole groups of sequences, where sequences within 100 km and a year of each other form one group. The reading uses the wider of the two. A count outside the range is a count outside the range. This page does not say why. The plan, with the rules and the known-good checks, was fixed before any stated figure was set beside a count.

Reading against the stated 95 percent: below if the upper bound is under 95 percent, above if the lower bound is over 95 percent, consistent if the interval lies within 92.5 to 97.5 percent, otherwise cannot tell with the reason STRADDLES EDGE. Fewer than 30 rows or fewer than 10 separate groups of nearby sequences is cannot tell with the reason TOO_WIDE_TO_RESOLVE. A cell with no rows or no interval is cannot tell with the reason NO_INTERVAL_FORMABLE. Edges are closed, so an interval end equal to a stated figure is neither above nor below it. No size that matters is named for these cells, so the check for an interval that holds both zero and a size that matters is not applied. A range of 0 to 0 is a statement that none is likely, and a single event breaks it. Most rows at M5 and above have a range of 0 to 0, and those rows are inside unless one such earthquake happens. Without them, M3 and above holds 17,948 of 18,890 inside (95.0 percent, interval 92.2 to 97.1 percent, cannot tell (STRADDLES EDGE)).

What this page holds and what it leaves out

Read on this run: 250 events with a forecast, 14,258 versions, and 231,796 rows. Not yet readable: 45,269 rows whose window has not closed a week ago. Versions with no product to read: 17 deleted, 2 whose forecast file could not be read. Rows that cannot be read against the catalog: 788 where the product states no zone. These are counted apart and never folded into a share. Windows that opened before their version was stamped are listed apart and not scored: 109,840 rows from 4,575 of 14,239 versions. Most of those versions were stamped a few minutes after their windows opened, with a median of 6.3 minutes, and 105 of them more than a day after. Among scored rows, 935 come from versions the catalog indexed after the window opened, though stamped before it.

Older versions do not always state their zone in the forecast file. Where the forecast file states none, the zone in the same version’s data file is used. Where neither states one, the rows read cannot tell. The count comes from the USGS catalog as it stands on the day of the run, which can differ from what the USGS had when it issued a forecast. The split by the network that located the mainshock is shown and not scored.

Set aside: the shape of the full distribution of the number, spatial forecasts, which the USGS says it does not issue, and any judgment of the forecast model.
