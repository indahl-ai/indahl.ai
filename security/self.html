Security Records

The SECRECORDS checks, run on indahl.ai domains

indahl.ai runs the checks of the SECRECORDS desk on its own domains, with the same code and the same outcome labels the desk prints for other domains. The desk reads two claims. A Strict-Transport-Security header that states preload is held against the preload list requirements (a max-age of at least 31,536,000 seconds and includeSubDomains). An SPF record is held against the limit of 10 DNS lookups. AGREE means the record can do what it states. DISAGREE means it cannot. NOT_COMPARABLE means there is no statement to read or the read failed.

What indahl.ai fixes is what its own server code sends. Changes to DNS records and to heuremen.org, which is served by GitHub Pages, are decided by the owner of each domain and are listed in the records until they are made. The checks are rerun after every change to these headers.
