TAPE · What Was Published, and When

Why this number has no kit, and what can be checked.

Division: HERMES

A record of what was published, in the order it was published

About every half hour every live feed is hashed and a line is added to a chain, and whenever a public page changes every public page is hashed into the chain too. Each line carries the hash of the line before it, so changing an old line changes every line after it. Each run also writes a beacon value built from the newest drand round, the feeds of that run, the previous line and the root of the newest quantum-bits entry, which holds bits read from an IBM processor. Nobody could have known it before those inputs existed, and anyone can recompute it. Every few hours the chain is stamped with OpenTimestamps, which ties it to Bitcoin’s timeline. No coin is held and no mining is run.

Loading.

A hash proves that a page or feed existed in exactly this form at that time. It does not prove the content is true. The plan, the chain, every leaf behind every line and the verifier are public in the repository, and the verifier needs only Python. Run python3 tape_verify.py in that folder to check the whole chain.

Each release of the site is also stamped on its own, with Internet Archive copies of what changed: STAMPS.

Need a receipt for a file? VAULT hashes a file in the browser and adds the hash to this tape. The file never leaves the computer.

Plan, code and trend history for this page are public: tape. Every plan was committed before the data it describes.

Software this page uses or compares against: OpenTimestamps client (git · PyPI), drand (git).
