TEST DRIVE

Give it an arXiv id and it reads the paper: retraction, correction and concern notices, the current version, whether its code and data links still answer, and every reported test statistic and percentage recomputed from the paper’s own numbers. A DOI gets the record checks. No key and no account. The answer comes straight from the indahl.ai MCP server, the same one assistants use, with its signed receipt.

The receipt holds the SHA-256 of the answer as sent and an Ed25519 signature that can be checked against the public key. It shows that indahl.ai produced this answer at that time. It does not show that the answer is right. paper_check sends the id typed to Crossref, doi.org and arXiv; paper_statistics sends the arXiv id to arxiv.org; check_reported_statistics sends the text nowhere; qia_measured reads IBM’s published record and our own published hourly runs, and sends nothing. The server keeps nothing (details).
